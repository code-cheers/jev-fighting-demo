# 录屏复现

本次录制使用 desktop-recorder 技能的“探索、脚本、预演、录制、导出”流程。原生窗口录屏未能稳定取得浏览器画面，因此用 CUA 浏览器截图采集实际页面帧，依据每帧真实时间戳编码；没有替换模型回答、加速比赛或人为设定胜者。

步骤：准备全新待机页面并确认双方费用为零 → 将舞台与右侧对比保持同屏 → 录制2秒待机 → 点击开始真实API对局 → 保持固定视野录制48秒 → 第48秒重新对齐比赛与完整结算面板，留出8秒阅读结算 → H.264导出1920×1080。最终视频56.30秒、30fps；页面采集目标20fps。视频为无音轨，标题、说明条与点击提示是导出时添加的展示元素。

只采集游戏页面，没有采集密钥、账户页、聊天窗口或其他浏览器标签。录屏所对应的实测值见 `demo-result.json`；原始截图和本机服务日志未提交。
